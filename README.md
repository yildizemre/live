# Hype Live — tanıtım sitesi

Takipçilerini canlı yayınına al: kodu paylaş, takipçiler kameralarıyla katılsın, kimi yayına alacağını sen seç; YouTube, Instagram ve TikTok'a grafiklerle aynı anda yayınla.

Statik site (HTML + CSS + JS, derleme gerektirmez). Yerelde açmak için:

```
npx http-server . -p 5240
```

- `index.html` — tek sayfa (TR)
- `style.css` — tema ve responsive düzen
- `main.js` — menü, kaydırma animasyonları, şov araçları sekmeleri
- `img/` — logo ve uygulama ekran görüntüleri
