# Rejivio — tanıtım sitesi

Telefonundan çok kameralı canlı yayın rejisi: kodu paylaş, takipçilerin ya da ekibin kameralarıyla bağlansın, kimin yayında olacağını telefondan veya web panelden sen seç; YouTube, Instagram, TikTok ve daha fazlasına grafiklerle, istersen gecikmeli olarak aynı anda yayınla.

Statik site (HTML + CSS + JS, derleme gerektirmez). Yerelde açmak için:

```
npx http-server . -p 5240
```

- `index.html` — tek sayfa (TR)
- `style.css` — tema ve responsive düzen
- `main.js` — menü, kaydırma animasyonları, yayın görüntüsü sekmeleri, APK linki
- `img/` — Rejivio logosu, ikonlar ve uygulama ekran görüntüleri
